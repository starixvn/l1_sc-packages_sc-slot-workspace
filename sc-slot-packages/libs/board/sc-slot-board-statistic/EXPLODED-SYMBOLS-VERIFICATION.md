## 🔍 **What Gets Verified**

### ✅ **explodedSymbols Validation**
- **Array Length**: Must have exactly 30 elements (6×5 grid)
- **Position Accuracy**: Each exploded symbol must match original board position
- **Count Consistency**: Symbol counts in `icons` must match exploded counts
- **Data Format**: Uses -1 for non-exploded, actual symbol values for exploded

### ✅ **Additional Validations**
- **newSymbols Structure**: Correct length and placement
- **Bet Data**: Calculation accuracy (when present)
- **Tumble Structure**: Required fields and data types
- **Cross-Reference**: Icons data vs actual exploded symbols

### ✅ **Bet Data Integration**
- ✅ Added betLevel, coinValue, betMultiplier, betAmount to BoardResult interface  
- ✅ Calculate and populate bet data in processSettlement method
- ✅ Include bet amount calculation: `betAmount = coinValue × betLevel × betMultiplier`
- ⚠️  **Note**: Bet data appears in newly generated chains (legacy chains may not have it)

## 📚 **Technical Details**

### Validation Logic
```typescript
// Position mapping validation
tumble.explodedSymbols.forEach((symbol, pos) => {
    if (symbol !== -1) {
        // Must match original board at same position
        assert(symbol === originalBoard[pos]);
    }
});

// Count consistency validation
Object.entries(tumble.icons).forEach(([symbolStr, iconData]) => {
    const expectedCount = iconData.count;
    const actualCount = explodedCounts[symbol];
    assert(actualCount === expectedCount);
});
```
